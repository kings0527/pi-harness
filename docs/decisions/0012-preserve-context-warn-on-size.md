# ADR-0012: 完整保留上下文，超量只告警
背景：静默截断会隐藏早期证据和错误，使后续诊断失去因果链。
决策：knowledge index、Board 注入、close summary 与 subagent 输出均保留完整内容。
决策：不得按固定字节数静默裁剪；筛选视图必须保留可见的完整来源路径。
注入内容估算达到当前模型 context window 的 20% 时，仅发一次 stderr + event 告警。
告警给出 knowledge/Board 占用，并提示检查过期、错误、重复或过长条目；不自动删除。
理由：大上下文模型可容纳完整证据，显式提醒比隐藏内容更可诊断。
放弃：固定 3000-byte 上限、按尾部截取，以及自动清理 knowledge。
