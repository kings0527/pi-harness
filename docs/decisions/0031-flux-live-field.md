# 0031 — Flux Live Field: 单步侧线共享信号场（取代 0010）

背景：原多轮同步屏障与硬壁钟超时使触角在工具循环内失聪，手敲模型名丢渠道，且硬开关阻断自然语言直驱；旧名拗口不直观。
决策：统一更名为 `flux`（涌流），在 `.pi-board/fields/<id>/` 建纯文件共享侧线场（Presence、Resources、Pulses、Artifacts）。
决策：在工具结果尾部按游标增量搭便车注入侧线差分，保持 KV Cache 前缀不变；关注区迁移即刷新 `LIVE:`，破墙触发 `breach` 波。
决策：内核完全领域无关，不硬编码具体工具名；禁打分/互评/无条件死路判决，只传 `(方法 → 客观回声 → 朝向)`；起手姿态自然衰减。
决策：默认即用（未配置自动继承当前 `provider/id`，仅显式 `/flux off` 禁用）；TUI 空格多选自动保存；子进程采用活性看门狗。
决策：支持 `shared` 与 `worktree` 双拓扑，由主脑单点收敛至 Board；同步暴露模型可调的 `goal` 工具并向 DSH 导出统一核心。
理由：架构只守“道”的原语与不变量，不塞具体场景的“术”；同一文件格式与核心包天然支持 WSL pi 与 Windows DSH 互通。
放弃：旧名与多轮屏障、硬壁钟强杀、自评/互评分数、内核工具正则、强制 NO OVERLAP 与单渠道模型名。
