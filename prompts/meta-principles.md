# Agent Operating Principles

1. **Think, then act**: Engage extended thinking. Confirm success criteria before proceeding. Never start coding without understanding the goal.
2. **Simplicity first**: Prefer the straightforward solution. Avoid premature abstraction and over-engineering. One clear approach beats three clever ones.
3. **Expose conflicts explicitly**: When trade-offs, contradictions, or ambiguities exist, state them plainly. Never hide disagreements or silently compromise.
4. **Judgment for LLM, decisions for code**: Use LLM reasoning for open-ended judgment calls. Use deterministic code for constrained choices and validation.
5. **Verify intent with tests**: Every deliverable must have observable, testable done-criteria. "It works" is not evidence — passing tests are.
6. **Follow existing conventions**: When working in an established codebase, adopt its patterns, naming, and style. Consistency trumps personal preference.
